## Changes

Correctness and honesty release addressing all 8 findings of the first full (retroactive) code review of the shipped app. No change to the fix mechanism itself — the plugin rename and reboot contract are untouched.

- **Worker IPC rewritten** (`easy-tool/NvidiaFixTool.ps1`): the elevated helper now reports through enumerated exit codes (exhaustive state × action matrix) read from the process object. The `%TEMP%` result file — which silently lost results when a standard user elevated with a different admin account — is removed entirely.
- **CPU measurement rewritten, twice-vetted** (both scripts): `Get-Counter` (broken on non-English Windows) was first replaced per plan with `Get-Process` deltas — which review round 1 proved silently fabricates 0% for the SYSTEM-owned container processes when unelevated. Final mechanism: CIM `Win32_Process` Kernel+User time deltas — locale-neutral, unelevated-readable, with a null-sample guard that reports "could not measure" rather than ever fabricating a number. Verdict logic now distinguishes measured / not-running / measurement-failed, and "healthy" verdicts require an actual measurement.
- **Conflict state** (both scripts + worker): stock `.dll` and `.off` both present (e.g. after an in-place driver reinstall) is now detected and reported honestly; Fix and Revert decline to act rather than guess.
- **GUI flow**: plain-English consent dialog before elevation (what is renamed, nothing deleted, what you lose, restart required); dedicated post-Revert "restart to finish" state (previously the restart instruction was wiped by an immediate re-diagnosis); honest failure verdicts on Undo; buttons disabled during operations to prevent re-entry via queued clicks.
- **Mechanical fixes**: CLI self-elevation now quotes the script path (paths with spaces previously broke Fix/Revert relaunch); one spin threshold everywhere (previously a hard-coded 3% produced contradictory verdicts on 64-thread CPUs); ACL grants use the `*S-1-5-32-544` SID (localized "Administrators" group names broke the old form); CLI no-op and conflict cases resolve before prompting for UAC.
- **Docs**: README manual commands and verification snippet updated to the locale-neutral forms; conflict state documented; easy-tool ReadMe step updated for the consent dialog.
- **Deferred to on-hardware verification** (recorded in plan and CR): real Fix/Revert renames, the RunAs exit-code transport end-to-end, cross-account UAC, conflict state in vivo, localized-Windows run.
