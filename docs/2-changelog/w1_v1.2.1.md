## Changes

Closes the two Minor observations left open at v1.2.0 (remedies specified by the v1.2.0 round-3 reviewer):

- **Apply-handler failure verdicts** (`easy-tool/NvidiaFixTool.ps1`): when applying the fix fails or can't be confirmed, the bold verdict now turns orange and says so ("The fix was not applied" / "Could not confirm what happened") instead of leaving the previous "Problem found - and this tool can fix it" standing above a failure log — mirroring the Undo pattern shipped in v1.2.0.
- **Unknown worker exit codes**: `Invoke-Worker`'s `default` branch now returns `$null`, so out-of-contract codes land in the honest unknown-outcome path in both handlers — matching the message it logs and the behavior ARCHI §14 already documented.
- **Docs**: ARCHI §13 button-disabling wording corrected; v1.2.0 test summary (`docs/4-unit-tests/w1_v1.2.0_test.md`) records the post-release on-hardware verifications: elevated RunAs exit-code transport end-to-end (mutation-free, exit 2 intact) and the owner's live GUI pass.
- **Open observation** (CR): on a declined UAC prompt the verdict under-claims ("could not confirm" where the log knows nothing changed) — inherited from the approved v1.2.0 pattern; future patch candidate as its own change.
